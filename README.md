# 100 Days of JavaScript Challenge

This repository documents my journey of building 100 JavaScript projects in 100 days.  
The objective of this challenge is to strengthen my understanding of JavaScript, improve problem-solving skills, and gain hands-on experience through consistent practice.

---

## About

This challenge focuses on:
- Strengthening core JavaScript concepts  
- Building practical, real-world projects  
- Improving consistency and discipline  
- Developing a structured and professional portfolio
